# Shodwe Hotel Data-Analysis-Dashboard(Interactive Dashboard creating using MS Excel)
## Project Objective 
To analyze overall hotel performance using data visualization and interactive dashboards to monitor revenue, bookings, cancellations, occupancy, and customer satisfaction, helping management make informed business decisions and improve hotel performance.

## Question (KPIs)
- What is a KPI, and why is it important in hotel analysis?
- What is the total revenue generated by the hotel?
- How many total bookings were recorded?
- What is the average customer rating?
- How many bookings were cancelled?
- What is the booking cancellation percentage?
- What is the hotel occupancy rate?
- How do weekday and weekend revenues compare?
- Which room category has the highest average rating?
- Which hotel has the highest customer rating?
- How does weekly revenue change over time?
- How can KPIs help improve hotel performance?
